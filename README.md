**📌 Project Overview**
# SAP-End-User-Training-Academic-P2P-with-AP-Project-
This is a practical SAP end-user case study showing the flow from purchase requisition/purchase order to goods receipt, vendor invoice, payment, and accounting review. The project is designed for interview presentation, not as a claim of professional work experience.


**🎯 Objective**
Understand the end-to-end P2P process.
Understand the connection between procurement and accounting.
Learn basic SAP FICO transaction flow.
Understand Accounts Payable, GR/IR, vendor accounting, and reconciliation.
**🔄 Process Flow**


Purchase Requisition → Purchase Order → Goods Receipt → Vendor Invoice → Payment → Reconciliation


**🧾 SAP T-Codes Covered**
Activity	T-Code
Purchase Requisition	ME51N
Purchase Order	ME21N
Goods Receipt	MIGO
Vendor Invoice	MIRO
Vendor Line Items	FBL1N
Accounting Document	FB03
Manual Vendor Payment	F-53
Automatic Payment Run	F110


**📊 Key Concepts Covered**
Purchase-to-Pay (P2P)
Accounts Payable (AP)
Vendor Accounting
Goods Receipt / Invoice Receipt (GR/IR)
Invoice Verification
Vendor Open Items
Payment Clearing
Reconciliation
Basic G/L impact


**💡 Key Learning**

Through this project, I developed an understanding of how operational purchasing transactions are connected with financial accounting in SAP and how vendor invoices, payments, and reconciliation are handled.
